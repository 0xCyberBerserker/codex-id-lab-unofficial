About

Unofficial Linux packaging automation for Codex UI.

Codex I+D Lab - Unofficial exists to make frequent Codex UI updates repeatable on Linux systems without committing upstream binaries or maintainer-local runtime data to git.

Scope

  • Verify current source metadata from the signed official Linux repository.
  • Preserve the official Linux-native runtime unchanged.
  • Add launcher and desktop integration.
  • Generate Arch/CachyOS packages plus experimental Debian and RPM packages.
  • Validate manifest, checksums, and privacy boundary.

License

Original automation, patches, packaging metadata, website material, and documentation use the PolyForm Noncommercial License 1.0.0. Upstream components retain their own terms.

Non-Goals

  • No official OpenAI support claim.
  • No extracted upstream app bundles committed to git.
  • No Codex chats, profiles, sessions, runtime state, tokens, or private keys.
  • No AUR publication before redistribution and trademark review.
