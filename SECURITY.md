# Security Policy

## Supported Versions

Security fixes target the current `main` branch and latest release. Older generated packages are not maintained.

## Reporting A Vulnerability

Do not disclose suspected vulnerabilities, credentials, tokens, private paths, or runtime data in a public issue.

Use GitHub's private vulnerability reporting or a private security advisory for this repository. Include affected version, reproduction steps, impact, and any proposed mitigation.

## Scope

Reports may cover repository automation, release workflows, package integrity, update verification, privilege handling, privacy controls, and Linux-specific patches.

Vulnerabilities in upstream Codex UI or OpenAI services should be reported through OpenAI's official security channels.

See [docs/security.md](docs/security.md) for repository privacy and release controls.

# Política de seguridad

## Versiones soportadas

Las correcciones de seguridad se aplican a la rama `main` y a la última release. Los paquetes anteriores no se mantienen.

## Informar de una vulnerabilidad

No publiques vulnerabilidades sospechadas, credenciales, tokens, rutas privadas ni datos de ejecución en una issue pública. Usa el informe privado de vulnerabilidades o un aviso privado de GitHub e incluye versión afectada, reproducción, impacto y mitigación propuesta.

El alcance incluye automatización, workflows, integridad de paquetes, actualizaciones, privilegios, privacidad e integración Linux. Las vulnerabilidades de Codex UI u otros servicios upstream deben enviarse por los canales oficiales de OpenAI.
