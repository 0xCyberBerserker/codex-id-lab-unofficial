# computer-use-linux — experimental preflight

Five main-bundle contracts match. The MIT native client/transport and 22 upstream fixture tests are imported, with four Lab regressions. JSON-RPC frames and concurrency are bounded; all native observations/input require an app target, and failed input is never replayed. Tests launch only an owned temporary MCP fixture, not a desktop backend.

The upstream Rust backend spans 23,783 lines across desktop-specific implementations, including command runners, browser integration and input backends. It is not copied or compiled before a separate dependency/hook review and controlled permission test. This is a bounded partial integration, not working desktop control. Screenshot permission does not imply input permission.

Run `node --test linux-features/computer-use-linux/native.test.js`. Source/commit/license and modifications are in the import inventory. No runtime hook or backend binary is staged. Disabled profiles add no resources, permissions or activity; enabling fails before mutation.
